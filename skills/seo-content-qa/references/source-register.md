# Source Register

The rules in this skill paraphrase the pages below. "Opened 28 Nov 2026" means the page was fetched on that date (Asia/Singapore) and the passages this skill uses were read. None of these checks inspected an account, a website or a business. Recheck the relevant page before a consequential decision, and review the whole register at least quarterly.

IDs C01 to C08, C11 and C13 keep the source IDs in the Content Evidence, Briefing and Publishing QA playbook v1.2 (File 12), so each rule can be traced back. C17 keeps the ID the SEO Content Evidence Skill gives the documentation updates log. C18 is an addition for this skill. File 12's C09, C10, C12, C14 and C15 cover dates, links, URL Inspection, video and technical requirements, which belong to publishing and production checks, so they are not used here. Finding IDs use the `QA-` prefix, claim checks `QC-`, and dossier claim IDs `CL-`.

## Differences from the playbook

- **C02:** the playbook records manual fact-checking, including metadata, alt text and structured data. The current page says it is critical to fact-check and review all AI-generated content before publishing. The skill uses the current wording.
- **C03:** the displayed update moved from 28 Aug 2026 in the playbook to 23 Nov 2026. C17 records that the 23 Nov change added a back-button hijacking FAQ, which this skill does not use. The playbook's summary names doorway, scaled content and link spam. Pass 3 uses the page's current descriptions of eight policies that can show on one page; link spam and link attributes belong to publishing checks.
- **C05 and C06:** consistent with the playbook: no fixed length limit for titles or meta descriptions, display truncation, and no guarantee the supplied text is shown.
- **C18:** not in File 12's register. The proposed Visual Semantics and Page Presentation playbook (File 14, not yet in File 04's index) uses this page for its main-content and page-experience questions, which pass 3 borrows.
- **C17:** the entries from 20 to 27 Nov 2026 added a back-button hijacking FAQ to the spam policies (23 Nov), generative AI controls and attribution pages and a ranking section (24 Nov), and sitemap and crawl-error guidance (27 Nov). None changes a passage this skill uses.

When a page changes, record the ID, the section, the check date, what changed and which reference file it affects. Update the reference file first, then this register.
