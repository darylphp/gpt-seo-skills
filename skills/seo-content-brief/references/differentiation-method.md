# Differentiation Method

1. **Baseline expectation.** Identify the minimum answer, context, limitations and next step the reader needs.
2. **Common failure.** Use supplied, dated market observations to state a relevant omission or source of confusion. When none was supplied, mark the observation unavailable and describe the reader risk as a hypothesis if useful.
3. **Primary differentiator.** Select one useful contribution the approved dossier supports. Record the evidence IDs, purpose and limits.
4. **Supporting asset.** Choose an optional table, visual, tool or proof asset only when it materially improves the decision. Record permission and owner if applicable.
5. **Practical consequence.** Specify the better choice, task completion or avoidable mistake that the contribution supports.

Useful contributions include documented first-hand experience, expert input, verified operational detail, original data, transparent comparison, compatibility guidance, a decision aid or clear source-led synthesis. A checklist can be a useful contribution if its logic and limits are evidence-backed. If a tool is proposed, identify the approved method and its validation dependency before treating it as usable proof.

Check whether the idea helps the intended reader, belongs to the exact page, can be delivered without overstating the evidence and can be maintained. Greater length, extra FAQs, a competitor outline, broader keyword coverage or visual polish alone do not establish value. A gap in competitor coverage does not establish demand. Return to B2 if a viable contribution lacks essential support. Return to B1 if the page has no distinct reason to exist.
