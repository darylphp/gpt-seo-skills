# Direct-file behaviour review, 27 November 2026

These are synthetic, read-only simulations using the runtime files directly, not installed-skill runs. The main session wrote the adaptation and scored the outputs. Each generation used a fresh delegated GPT context (`fork_turns=none`) with only a fixture and the runtime path in its task. The exact model identifier was not exposed by the orchestration surface and is not asserted. Agents shared a filesystem; withholding other artifacts was by instruction, not filesystem isolation. No live assets, account calls or customer messages were involved.

The runtime manifests were frozen before each round. Each manifest identifies all nine runtime Markdown files by SHA-256. Inputs and unedited full outputs are retained. The three scenarios exercise selected criteria from the acceptance document; they are not 26 separate acceptance-case runs and do not constitute independent editorial approval.
