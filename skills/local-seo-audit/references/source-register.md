- Existing action-specific authorisation is recognised. Partial approval is recorded by action; the report never authorises execution. Priorities, report statuses and recovery records are operating methods.
- A supplied performance export does not certify current verification or access state. Supplied screenshots and exports do not become live observations [G10].
- Current local-ranking wording uses popularity in the overview and Prominence as a subsection. These are source terms, not a weighting formula [G18].
- Review rules prohibit incentives and selective solicitation; disclosure does not create an exception [G11]. Staff solicitation quotas differ from an internal business measurement goal.
- Appeals use the current live tool. Do not create a replacement profile or hard-code an old evidence timer [G21].
- Conditional bulk verification is outside this single-location report. Do not infer eligibility from total profile count; use location-level records and a specialist check for that request.
