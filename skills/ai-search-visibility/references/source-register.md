# Source Register

The rules in this skill paraphrase the pages below. "Opened 28 Nov 2026" means the page was fetched on that date (Asia/Singapore) and the passages this skill uses were read. None of these checks inspected a Search Console account, a website or a business. Google revises these pages often: recheck the relevant page before a consequential decision, and review the whole register monthly, in line with the AI playbook's schedule.

IDs G-001 to G-005, G-009 to G-011 and G-017 keep the evidence IDs in the Google Generative AI Search Evidence and Observation Ledger v1.4 (File 07), so each rule can be traced back. G-021 to G-026 are additions for this skill, proposed for File 07's next revision. X-01 to X-04 cover other platforms, which the Google Generative AI Search Operating Playbook v1.4 (File 06) leaves to each platform's own documentation. Reports use the separate prefixes `S` for sources, `OB-` for observations and `AC-` for actions.

## Differences from the playbook

- **Playbook dates:** Files 06 and 07 v1.4 record checks up to 24 October 2026, with the next monthly review due 19 November 2026. This register is a skill source check, not that review. File 06 and File 07 still need their own update.
- **G-005:** File 07 built G-005 from the crawler table and the Search control help. On 24 November 2026 Google moved Google-Extended's scope to its own page, and the crawler table now links there. The new page covers training "future generations" of foundation models for commercially available products, and grounding in those products "aside from Search and other Search services"; by its sentence structure, that exception qualifies grounding, not training. It says Google-Extended doesn't affect Search inclusion and isn't a ranking signal. This is consistent with G-004, which still points to Google-Extended for limiting training of the models behind Search AI responses. Neither page addresses content collected before a disallow.
- **G-021, G-022 and G-024:** published on 24 November 2026, after File 06 v1.4. They bring the controls together and describe link selection, without adding a new control. G-022 adds the routes for reporting errors and the advice on dates.
- **G-011:** the displayed update moved from 28 Aug 2026 in the playbook to 23 Nov 2026. G-017 records that the 23 November change added a back button hijacking FAQ, which this skill doesn't use.
- **G-002:** consistent with File 07 G-002. The skill words chart and table totals as Google does, aggregated by property and by page and able to differ, rather than describing how one AI response is counted.
- **G-023, G-025 and G-026:** not in File 07. G-026 records the 9 to 11 November 2026 logging error, with no restoration note as of 28 November 2026.
- **Not used:** File 07's G-006 to G-008 and G-012 to G-016, G-018 to G-020, and the patent, research and study entries. The skill has no rule that rests on them. G-016's link formats are now described in G-022.
- **X-01 to X-04:** outside the Google-only scope of Files 06 and 07. The rules in [other platforms](other-platforms.md) keep them separate.

When a page changes, record the ID, the section, the check date, what changed and which reference file it affects. Update the reference file first, then this register.
