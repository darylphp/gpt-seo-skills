# Source Register

The rules in this skill paraphrase the Google pages below. "Opened 28 Nov 2026" means the page was fetched on that date (Asia/Singapore) and the passages this skill uses were read. None of these checks inspected an account, a website or a business. Recheck the relevant page before a consequential decision, and review the whole register at least quarterly.

IDs C01 to C04, C10 and C13 keep the source IDs in the Content Evidence, Briefing and Publishing QA playbook v1.2 (File 12), so each rule can be traced back. C16 and C17 keep the IDs the SEO Content Evidence Skill gave them. C18 and C19 are additions for the ecommerce routes. File 12's C05 to C09, C11, C12, C14 and C15 cover titles, snippets, images, dates, structured data, URL Inspection, video and technical requirements, which belong to publishing work, so they are not used here. Claim IDs in a draft use the separate `CL-` prefix.

## Differences from the playbook

- **C02:** the playbook's summary already records manual review, including metadata, alt text and structured data. The current page says it is critical to fact-check and review all AI-generated content for accuracy and trustworthiness before publishing. The skill uses the current wording. C17 dates this update to 1 Oct 2026.
- **C03:** the displayed update moved from 28 Aug 2026 in the playbook to 23 Nov 2026. C17 records that the 23 Nov change added a back-button hijacking FAQ, which this skill does not use. The doorway, keyword stuffing, scaled content and thin affiliation passages used here are consistent with the playbook's rule.
- **C10:** in the playbook, this page supports link checks at publishing. The skill uses it for anchors written in the draft and for the paid-link note on the affiliate route.
- **C13:** the playbook summarises this page as useful content and foundational SEO, with no special requirements for generative AI features. The skill also uses its statements that no special writing style or chunking is needed, and that building separate pages for each query variation to manipulate rankings violates the scaled content abuse policy.
- **C16, C18 and C19:** not in the playbook's register. C16 separates a site's own review content from third-party user reviews, for the affiliate route. C18 and C19 are added for the category route, where copy is often written for every facet.
- **C17:** between 1 Oct and 27 Nov 2026, no entry changed C01, C04, C10, C13, C16, C18 or C19. The 24 Nov entries added a ranking section and pages on generative AI controls and attribution, and the 27 Nov entries changed sitemap and 404 guidance. This skill uses none of them.

When a page changes, record the ID, the section, the check date, what changed and which reference file it affects. Update the reference file first, then this register.
