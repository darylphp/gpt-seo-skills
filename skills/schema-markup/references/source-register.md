# Source Register

The rules in this skill paraphrase the pages below. "Opened 28 Nov 2026" means the page was fetched on that date (Asia/Singapore) and the passages this skill uses were read. "Search-result text" means the passage was confirmed from the page's indexed text in search results on that date, without opening the page. "Carried forward" keeps the playbook's earlier check, not reopened for v0.1.0. None of these checks inspected an account, a website or a business. Recheck the relevant page before a consequential decision, and review the whole register at least quarterly.

## Differences from the playbook

- **Events (M10):** File 05 v1.3 says Google's event experience requires public bookability and a physical location, and that online-only events are unsupported. The Event structured data guide fetched on 28 Nov 2026 documents online events with `VirtualLocation`, a join URL and a required UTC offset, and does not contain the public-bookability or physical-venue wording. That wording appears in Google's [Actions Center events eligibility page](https://developers.google.com/actions-center/verticals/events/overview) (search-result text, 28 Nov 2026), which covers a separate integration. This skill follows the Event structured data guide. File 05 should be corrected at its next review.
- **Gallery (M03):** its displayed update, 16 Oct 2026, is later than File 05's checks. The 25 features it lists are recorded in [feature support](feature-support.md). FAQ, how-to, sitelinks search box and practice problem are absent.
- **FAQ (M15):** File 05 says FAQ rich results stopped appearing from 7 May 2026 and the documentation was removed in June 2026. The documentation log dates the removal to 15 June 2026, after a deprecation notice on 8 May 2026. The operating rule is unchanged.
- **Properties (M02):** the introduction's statement that fewer complete and accurate recommended properties are better than many incomplete ones is added to the property map rules. It is consistent with File 05's rule to include only properties backed by real information.
- **Merchant Center (M09):** File 05 does not cover it. Added because Merchant Center requires markup in the server's HTML, while Google Search can read script-inserted JSON-LD (M02).
- **Documentation log (M15):** between File 05's 19 Oct 2026 review and 27 Nov 2026, no entry changed the general guidelines, review snippets, site names, products, breadcrumbs, Q&A or events. The 18 Nov 2026 book actions entry is not used here.

When a page changes, record the ID, the section, the check date, what changed and which reference file it affects. Update the reference file first, then this register.
